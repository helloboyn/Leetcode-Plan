# LeetCode 75 Study Plan 🚀

## Overview
LeetCode 75 is a curated list of 75 essential coding problems that cover key topics in Data Structures and Algorithms (DSA). This study plan is designed to strengthen problem-solving skills for coding interviews and competitive programming.

## 📌 Topics Covered
- **Arrays & Strings**
- **Two Pointers**
- **Sliding Window**
- **Prefix Sum**
- **Hash Maps & Sets**
- **Stack & Queue**
- **Linked List**
- **Trees (DFS & BFS)**
- **Graphs (DFS & BFS)**
- **Binary Search**
- **Dynamic Programming (1D & 2D)**
- **Bit Manipulation**
- **Trie**
- **Intervals**
- **Monotonic Stack**
